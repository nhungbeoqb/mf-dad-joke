A single dad joke for the Dad Joke Showdown: a father at the family barbecue, three beats, and a twist on the very last word — the burgers are medium-rare, and so, it turns out, is his patience. `main.py` writes the joke (169 characters, inside the 200-character gate) to `/output/entry.txt`.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
